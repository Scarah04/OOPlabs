Object-Oriented Programming in Java - Lab Solutions
===================================================
Requires JDK 17 or later.
Each exercise is in its own folder with a Main.java file:

    cd Lab01_Classes_and_Objects/Ex1_Car
    javac Main.java
    java Main

Or in one step (Java 11+):  java Main.java

Lab 11 contains Patterns_Demo (Singleton, Factory, Strategy, Observer) and
Library_Mini_Project (compile with: javac *.java, run with: java Main).
Programs that read input (Lab07 Ex1, Lab10 Ex1, Library menu) use the keyboard.
